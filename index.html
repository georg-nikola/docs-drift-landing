Why docs-drift?

Documentation gets out of sync with code. Code examples in README files break silently. Users copy-paste examples that no longer work. docs-drift validates that code examples in your documentation actually run without errors.

Fast

Local execution with no network calls. Parallel processing for large documentation sets. Changed-only mode for instant CI feedback.

Deterministic

Same input always produces the same output. No flaky tests, no random failures. Reliable results you can trust in CI/CD.

Simple

Single binary with no runtime dependencies. Zero configuration to get started. YAML config file when you need it.

Private

No SaaS, no telemetry, no data collection. Your code stays on your machine. 100% open source under MIT license.

Installation

Get started with docs-drift in seconds. Choose your preferred installation method.

Install via Go 
go install github.com/georg-nikola/docs-drift/cmd/docs-drift@latest
Build from source 
git clone https://github.com/georg-nikola/docs-drift.git
cd docs-drift
go build -o docs-drift ./cmd/docs-drift
.github/workflows/docs-check.yml 
name: Documentation Check

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  docs-drift:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - uses: georg-nikola/docs-drift@v0.2
        with:
          config: docs-drift.yml
          changed-only: true
          parallel: true

Quick Start

Get up and running in two simple steps.

1

Initialize configuration

$ docs-drift init

Created docs-drift.yml
docs-drift.yml 
version: 1

docs:
  paths:
    - README.md
    - docs/**/*.md

checks:
  code_blocks:
    enabled: true
    languages:
      - javascript
      - python
    timeout: 30s
2

Run the check

$ docs-drift check

Checking documentation...

README.md
  Line 25: javascript code block - passed
  Line 48: python code block - passed

docs/getting-started.md
  Line 12: javascript code block - passed

No drift detected!
Summary: 3 passed

Advanced Options

--changed-only

Only check files modified since the last commit. Perfect for fast PR validation.

--parallel

Enable concurrent execution for 2-4x faster validation on multi-core systems.

--verbose

Show detailed output including which files are being checked.

docs-drift:skip

Add to code fence to skip validation of specific blocks.
